# SIGA — Sistema Integrado de Gestión Académica
**Universidad Politécnica del Sur**

Prototipo web funcional desarrollado para la **Evaluación Parcial N°3.1** de la asignatura **Ingeniería de Requisitos (RQY1101)** mediante metodología ágil Scrum (Sprint 1).

## Integrantes — Equipo 11
* **Darien Carrasco**
* **Gerardo Linco**

## Funcionalidades Implementadas (Sprint 1)
* **HU-01:** Autenticación institucional (`@upsur.cl`) y acceso rápido de demostración.
* **HU-02.1:** Portal Estudiante con métricas de carga académica y navegación directa.
* **HU-03.1:** Inscripción de asignaturas con validación de cupos, prerrequisitos y topes horarios en tiempo real.
* **HU-04:** Consulta de horario semanal dinámico (Lunes a Sábado).
* **HU-05:** Resumen curricular de notas y asistencia.
* **HU-06:** Emisión de Certificado de Alumno Regular digital con folio único, Firma Electrónica Avanzada (Ley N° 19.799) y código QR verificable.

## Ejecución local
1. Instalar dependencias: `npm install` (o `bun install`)
2. Iniciar servidor de desarrollo: `npm run dev`
